## consequence
   1) Both libs export the same GLOBAL DEFAULT symbols, so the dynamic linker binds exactly one
      implementation per symbol. A patch must be placed on the address returned by
      dlsym(RTLD_DEFAULT, ...) and never on a hardcoded "libsmartbox base + vaddr".
   2) Whichever copy wins, the what=11 chain exists inside it, so the bypass conclusion does not
      depend on resolving the interposition question.
   3) The static analysis in this and the previous phases used libsmartbox's addresses; if the
      device's :core actually runs libagmmi's copy, every vaddr in this audit is off by a constant
      per function and must be re-derived from dlsym. Recorded as U10 / R21.
