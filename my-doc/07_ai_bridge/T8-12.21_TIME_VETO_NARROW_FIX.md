# T8-12.21 — 收紧时间意图否决词豁免

基线 `c3b570c0`（T8-12.20）。审查指出 `ir_match_time()` 的豁免实现与报告声明不符：`现在`+`是什么` 同时出现时整体跳过 `ir_has_any(IR_TIME_VETO)`，把 快递/生日/号码/格式 等其它否决词一并豁免。本轮只修这一处，不改退出意图，不做其它重构。

## 一、修改

`android/intent_route.c` 的 `ir_match_time()`，按审查建议实现 —— 单独遍历否决表，只跳过**内容恰好为** `"是什么"` 的那一项：

```c
if (!ir_has_any(n, IR_TIME_HIT)) return 0;
{
    int exempt_shi_sm = (ir_has(n, "现在") && ir_has(n, "是什么"));
    for (i = 0; IR_TIME_VETO[i] != NULL; i++) {
        if (exempt_shi_sm && strcmp(IR_TIME_VETO[i], "是什么") == 0) continue;
        if (ir_has(n, IR_TIME_VETO[i])) return 0;
    }
}
```

语义变化对照：

| 句子 | T8-12.20 行为 | T8-12.21 行为 |
|---|---|---|
| `现在是什么时间` | IR_TIME | IR_TIME（唯一豁免目标，保持） |
| `现在快递号是什么时间` | ❌ IR_TIME（快递被整体豁免，漏判） | **IR_NONE**（快递否决生效） |
| `现在生日是什么时间` | ❌ IR_TIME（同上） | **IR_NONE**（生日否决生效） |
| `现在房间号/订单/倒计时…是什么时间` | ❌ IR_TIME | **IR_NONE**（其余否决词全部生效） |
| `现在航班几点提醒` | IR_NONE（`现在`无`是什么`→全表生效） | IR_NONE（不变） |
| `日期格式是什么` | IR_NONE（无`现在`→全表生效） | IR_NONE（不变） |
| `我的生日是几号` / `快递几号到` | IR_NONE | IR_NONE（不变） |
| `现在几点了` / `现在几点` | IR_TIME | IR_TIME（不变，t8_02 真机文本断言仍绿） |

`IR_TIME_HIT`、其它意图匹配顺序、既有规则、退出意图、R13/R13-01：零改动。
