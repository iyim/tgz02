## 三、性能与兼容性预算（ARM32 / Android 8.1）

| 项 | 预算 | 说明 |
| --- | --- | --- |
| PNG 资源总体积 | 目标 ≤ 1.2 MB | 36 张实测合计约 1.1 MB（drawable-nodpi，不按密度复制） |
| 内存 | 角色页常驻 1 张 400×400（约 640 KB 解码）+ 快捷块 3 张缩略 | 其余插画按页加载 |
| 动画 | 属性动画 2 个（呼吸 scale、眨眼 alpha），无逐帧、无 Lottie | Mali-450 实测可跑 60fps（V1 同类动画已验证） |
| 首页帧率 | 状态切换为单次 160ms 交叉淡入 | 无常驻动画循环（除待机呼吸，可关） |
| 兼容 | API 27 无新依赖：PNG + View 属性动画 + GradientDrawable | 与现有 javac+d8 工具链一致 |
