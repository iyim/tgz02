# TG-Z02 V2 视觉设计规范（儿童友好型智能语音伙伴）

> 本规范是 T9-UI-01-V2 的唯一视觉事实来源。可执行版本：`prototype_v2/ds2.css`。
> V2 不改五大页面架构、不改导航体系、不改语音链路——只换视觉体系与角色资产。

---

## 1. 设计定位

**儿童友好的智能语音伙伴。** 三条平衡：

| 受众 | 要求 | V2 的做法 |
| --- | --- | --- |
| 孩子 | 有趣、活泼、有视觉主体 | 原创角色「布丁」是首页视觉核心；技能是插画大卡 |
| 家长 | 精致、现代、不廉价不幼稚 | 单一笔触（圆角+统一描边）、柔和但有辨识度的配色、无廉价渐变堆砌 |
| 使用 | 大字体、大按钮、状态清楚 | 正文 ≥17sp、标题 22–34sp、触控 ≥44dp（导航 88dp） |

---

## 2. 原创角色「布丁 PUDDIN」

- **造型**：果冻感圆方身体（蓝→紫渐变）、大椭圆脸部面板、大眼睛、腮红、头顶天线（天线球颜色=状态）、短手短脚。
- **气质**：友善、聪明、活泼；不低幼（有明确的"设备感"面板与肚皮屏）。
- **全部几何绘制**（`chars.js`），无第三方素材、无版权风险。
- **九个状态**：待机 / 唤醒 / 聆听 / 识别 / 思考 / 播报 / 开心 / 疑惑 / 休息 / 异常。
  每个状态 = 眼睛(睁/眯/垂) + 嘴型(笑/张/O/平/难过/说话波) + 天线球颜色 + 附加层
  (声波/思考泡/星星/汗滴/zZz/感叹号/音符) + 手臂角度 + 身体微倾。
- **语音状态映射**（首页九态）：

| 首页状态 | 角色状态 | 天线球 | 表情要点 |
| --- | --- | --- | --- |
| 待机 | idle | 琥珀 | 微笑、自然 |
| 唤醒 | awake | 橙 | O 型嘴、星星、身体前倾 |
| 聆听 | listening | 青 | 一眼大一眼亮、平嘴、声波、侧耳 |
| 识别 | thinking | 琥珀 | 眼睛向下看 |
| 思考 | thinking | 琥珀 | 思考泡 |
| 播报 | speaking | 绿 | 说话波型嘴 |
| 停止 | sleep | 灰 | 眯眼、zZz、明确"已停止" |
| 连续对话 | happy | 粉 | 眯眼大笑、张手 |
| 异常 | error | 红 | 难过 + 感叹号 |

- **动效规范**（APK 落地用，轻量）：
  待机呼吸（scale 1↔1.03，2.4s）与眨眼（每 4s 一次，120ms）用**属性动画**；
  播报时肚皮屏三条纹理做 200ms 交替；不引入 Lottie，不引入 GIF。
  状态切换 160ms 交叉淡入。所有动画可在「设置」里整体关闭。

## 3. 色彩体系（儿童模式为默认）

| 语义 | 值 | 用途 |
| --- | --- | --- |
| `bg` | `#FFF7EA` | 页面底（暖米白，不再是大片纯白） |
| `bg-deep` | `#FFEBD2` | 分区底、首页角色区 |
| `surface` | `#FFFFFF` | 卡片 |
| `line` / `line-2` | `#F3E3C8` / `#E8D2AB` | 2px 描边、分隔 |
| `text` / `text-2` / `text-3` | `#3A3040` / `#8A7A8F` / `#B7A88F` | 三级文字 |
| **`primary`** | `#FF8A3D` 活力橙 | 主按钮、选中态、首页快捷块 |
| `accent` | `#5FA8FF` 天空蓝 | 次级强调、日程块 |
| `ok / warn / err` | `#35C46A / #FFB020 / #FF5D5D` | 成功/提醒/失败 |
| `listen` | `#31D0B4` | 聆听状态 |

技能分类色（插画底色即分类色）：闹钟=暖橙、日程=天蓝、音乐=紫、天气=青蓝、设备=灰蓝、记忆=粉。

规则：
1. 状态色只出现在胶囊圆点、按钮与角色天线球，不做整页染色。
2. 渐变只允许两种：角色身体（蓝→紫）与快捷块（45° 同色系）；禁止装饰性大渐变。
3. 未启用技能：插画降饱和 40% + 透明度 55% + 「待接入/规划中」白底标签，一眼区分。

## 4. 字体（重点修复 V1 字体过小）

| 语义 | 字号 | 用途 |
| --- | --- | --- |
| 首页主标题 | **34** | 首页问候语 |
| 页面标题 | **26** | 一级页标题 |
| 重要功能文字 | **22–24** | 快捷块标题、技能卡标题、模型卡标题 |
| 关键状态提示 | **20**（胶囊 20 加粗） | 首页状态胶囊 |
| 正文 / 列表主行 | **17–19** | 卡片正文、记忆内容、闹钟时间 34 |
| 辅助文字 | **14–16** | 来源、时间戳、说明 |
| 底部导航标签 | **15 加粗** | 导航 |

行高 1.5；中文不缩写、不出现纯图标无文字的入口。**不为塞内容压字号**——内容超出就滚动。

## 5. 触控与布局

- 底部导航条高 **88dp**，五个入口每个都是 1/5 屏宽的大目标（儿童拇指友好）。
- 按钮标准高 **44dp**（模型/记忆行内小按钮 38dp）。
- 开关 **64×36**（V1 的 40×22 太小，儿童按不中）。
- 首页快捷块高 **132dp**（儿童模式）/ 96dp（简洁模式）。
- 列表行最小高 **64dp**。
- 密集小图标全部取消：V2 页面上没有 <24dp 的独立点击目标。

## 8. 文案规范（儿童口吻，家长可读）

- 角色 = "布丁"，自称"我"，称用户"你"，不称"用户"。
- 待机问候带名字："你好呀！我是布丁"。
- 异常文案不吓人、不甩锅："呜…网络断了一下 / 不是你的问题，稍等一下再试好吗"。
- 停止播报：**"好的，停下来了 / 想继续的话，再喊一声「天猫精灵」吧"**——
  明确终态，不出现"继续说完"。
- 关键状态 ≥20sp；说明文字短句，不超过两行。
- 「演示数据 · 非设备实况」为固定标注词，出现在模型/记忆/设置/关于页。

---

## 9. 插画规范

- 笔触统一：圆角形状 + `#3A4A6B` 描边（7–8px @800×600）+ 每技能专属双色渐变底。
- 全部带"生命感"：闹钟有脸、日历有铅笔与旗帜贴纸、音乐有带脸的音符与琴键。
- 角色 cameo：快捷块右下角的小插画即技能本体的"缩略生态度"。
- 源文件：`illustrations.js`（几何唯一事实来源）；导出 PNG 见 §10。

## 10. 资源导出与目录（可直接进 APK）

```
evidence/t9-ui-01-v2/
├── shots/                      20 张 1024x600 页面截图（验收用）
└── assets/
    ├── character/  puddin_{idle,awake,listening,thinking,speaking,happy,
    │                        confused,sleep,error}.png   400x400
    └── illustrations/ illus_{alarm,calendar,music,weather,device,
                             memory,settings}.png        800x600
```

APK 落地（T9-UI-02）：PNG 放 `res/drawable-nodpi/`（固定 px，避免按密度缩放），
命名 `puddin_*` / `illus_*`；或打包进 assets/ 由 BitmapFactory 直接解码。
角色在 APK 内进一步用两帧（眨眼/呼吸）做轻量动画，**不需要 Lottie/帧动画框架**。
