## 一、退出码修正

```sh
# 旧：无论写什么状态都 exit 0
finish() { printf '%s\n' "$1" > "$D/STATUS.txt"; ...; exit 0; }

# 新
finish() {
    status=$1
    rc=$2
    printf '%s\n' "$status" > "$D/STATUS.txt"
    printf '%s\n' "$status" > "$D/DONE.txt"
    chmod -R a+rX "$D" 2>/dev/null
    log "$status"
    exit "$rc"
}
...
if [ "$fails" -eq 0 ]; then
    finish "TEST PASS" 0
else
    finish "INCOMPLETE: see SUMMARY.txt (a required PASS or control condition did not hold)" 2
fi
```

`build_fail()` 保持 `exit 1`，三个码互不重叠：**0 = 全部验收通过，1 = 构建/工具链失败，2 = 跑完但验收不通过（含日志缺失）**。

## 二、逐项验收门禁

判据函数（按审查建议实现，另加数值判据、"缺文件"判据，以及 T8-12.13 新增的失败行计数判据）：

```sh
require_file()   { [ -s "$1" ]; }
require_result() { grep -q "^$2" "$1"; }              # $2 = RESULT 前缀
require_exit()   { grep -q "^EXIT=$2\$" "$1"; }
require_races()  { grep -q "^TSAN_RACE_WARNINGS=$2\$" "$1"; }
require_no_pass(){ ! grep -q '^RESULT: PASS' "$1"; }
require_races_gt0() {                                  # 数值判断，不是字段存在
    n=$(grep -h '^TSAN_RACE_WARNINGS=' "$1" | cut -d= -f2)
    [ -n "${n:-}" ] && [ "${n}" -gt 0 ]
}
fail_rows_eq() {                                        # 失败行必须恰好 N 条
    actual=$(grep -c '^FAIL  ' "$1" 2>/dev/null || true)
    [ -n "$actual" ] && [ "$actual" -eq "$2" ]
}
```

正对照的三项检查（同一份日志、三个独立计分项）：

```sh

must "B tsan_race_true has >=1 TSan report" require_races_gt0 tsan_race_true.txt
must "B tsan_race_true EXIT=66"            require_exit   tsan_race_true.txt  66
```

门禁项（每一项独立计分，任一不过 → 整体 INCOMPLETE）：

| 组 | 内容 | 项数 |
|---|---|---|
| **A** 正常主跑 | `plain_normal`：RESULT PASS + EXIT=0（2）；`tsan_normal`：RESULT PASS + EXIT=0 + RACES=0（3）；`fsm_normal`：RESULT PASS + EXIT=0（2）；`fsm_tsan_run`：RESULT PASS + EXIT=0 + RACES=0（3） | **10** |
